    How the trace works

    The button calls /api/trace on the same domain. CloudFront forwards it to a Lambda function in eu-central-1 that adds one to a DynamoDB counter and returns what it knows. The edge location comes from the x-amz-cf-pop response header, the round trip is timed by your browser, and the handler time is measured inside the function. If the live call fails, the page says so instead of showing a made-up trace.
